Keeping the toolkit current

Production rule: regulatory content must have an owner, official source, last-reviewed date, next-review date and change status. Do not publish a legal/regulatory claim without a source.

1. Monitor

Check CQC, GOV.UK and relevant statutory guidance for changes.

2. Verify

Read the primary source and record exactly what changed and which tools it affects.

3. Update

Change the central regulatory content, update the review date and add a short change note.

4. Alert

Show a visible “Updated” notice on affected tools so managers know to review their local policy.

For a production release, this update register should be moved into a small database/CMS so authorised administrators can update it without editing the website code.
